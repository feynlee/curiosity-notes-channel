Privacy Policy

Last updated: 2026-11-06

Curiosity Notes is an educational video channel run by one person. This page covers the Curiosity Notes Publisher tool and this website.

What the tool stores

When the channel owner connects TikTok, the tool stores the TikTok open ID, display name, avatar link and the access and refresh tokens that TikTok issues. Tokens are kept in the private settings of the cloud service that runs the tool for the owner. They are not sent to anyone else.

What the tool does with it

It uses that access only to post the channel's own videos to the owner's account and, optionally, to read the owner's own video list and view counts. It does not read private messages, follow accounts, or post anything the owner has not approved.

YouTube API Services

The channel's upload tool uses YouTube API Services to upload the channel's own videos to its own YouTube channel. By using it, the channel owner agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

The tool stores an OAuth token for the owner's Google account in the private settings of the cloud service that runs the tool for the owner. It requests two permissions: upload videos, and view the channel. It does not collect data about other YouTube users, and it does not share YouTube data with anyone.

The owner can revoke the tool's access to the Google account at any time at Google security settings. After revoking, or when the owner disconnects the tool, the stored token is deleted.

Visitors to this website

This site has no accounts, no cookies we set and no analytics. Our host may keep ordinary server logs.

Sharing

We do not sell or share personal data. We do not use TikTok data for advertising or to train AI models.

Deletion

The owner can disconnect at any time, which deletes the stored tokens, and can revoke access in TikTok under Settings, Security and permissions. To ask about data, write to curiositynotes@gmail.com.
